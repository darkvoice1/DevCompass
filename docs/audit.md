# 项目动态

动态记录项目、任务和阶段上发生过的宏观操作，方便以后翻看「这个项目最近做了什么」。它只记业务动作和一两句中文摘要，不记代码 diff，也不同步 Git。

仓库没有里程碑表。阶段用对象类型 `PHASE` 表示。

## 查询接口

```text
GET /api/v1/activities
```

| 参数 | 说明 |
| --- | --- |
| `projectId` | 必填，只看这个项目 |
| `objectType` | 可选 `PROJECT`、`TASK`、`PHASE`；不传则三种都返回 |
| `dateFrom` | 起始日期，包含当天 |
| `dateTo` | 结束日期，包含当天 |
| `page` | 页码，默认 1 |
| `pageSize` | 每页数量，默认 20，最多 100 |

规则：

- 不传 `objectType` 时，返回该项目下项目、任务、阶段的全部动态。
- 日期按 `Asia/Shanghai` 把日历日换成时间范围，包含当天。
- 开始日期不能晚于结束日期。
- 结果按创建时间从新到旧；时间相同时按 ID 倒序。
- 动态表不做软删除，查到的就是当时写下的记录。

## 会记哪些操作

业务保存成功后，在同一事务里写一条动态。失败（例如重复归档、非法状态、缺工作日志）不写。

| 对象 | 动作 | 典型摘要 |
| --- | --- | --- |
| 项目 | 创建、更新、改状态、归档、恢复归档、删除、恢复删除 | `创建项目「研发罗盘」` |
| 任务 | 创建、更新、改状态、删除、恢复删除 | `任务「实现接口」状态从 TODO 变为 COMPLETED` |
| 阶段 | 创建、更新、调整排序、删除、恢复删除 | `创建阶段「开发实现」` |

另外：

- 进度校准（改成手动或改回自动）记为项目 `UPDATED`。
- 任务完成后只记任务状态变更，不把工作日志再记一遍。
- 自动重算项目进度不记，避免刷屏。
- 相同状态再提交一次，不记。

## 不记什么

- 不记代码文件改动、Git diff、提交哈希。
- 不记请求关联 ID。
- 不记操作人。登录能力放到阶段六后再补用户字段。
- 不为历史上已经存在的项目、任务补动态。

## 请求示例

```text
GET /api/v1/activities?projectId=8&objectType=TASK&dateFrom=2026-09-01&dateTo=2026-09-21&page=1&pageSize=20
```

```json
  "message": "success",

    "total": 1,
    "totalPages": 1,
    "records": [
      {
        "id": 21,
        "projectId": 8,
        "objectType": "TASK",
        "objectId": 3,
        "action": "STATUS_CHANGED",
        "summary": "任务状态从 TODO 变为 COMPLETED",
        "createdAt": "2026-09-21T02:00:00Z"
      }
    ]
  }
}
```
